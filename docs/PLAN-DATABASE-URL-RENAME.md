# Plan: Rename DATABASE_URL to PSYPI_DATABASE_NAME

## Problem
- `DATABASE_URL` is a generic env var name that conflicts with other tools (Rails, Node.js apps, etc.)
- The code treats it as a full connection string, but we only need the database name
- `.env.example` documents the old name

## Changes

### Source files (already done)
1. **src/node_ffi.mjs**: `get_database_url()` → `get_database_name()`, reads `PSYPI_DATABASE_NAME`, fallback `'psypi'`
2. **src/db.gleam**: `get_database_url()` → `get_database_name()`, simplified `connect()` to always use `create_config` with the db name (removed old branching on empty string)

### Remaining work
3. **build/dev/javascript/psypi/db.mjs**: regenerate from Gleam source (`gleam build`)
4. **.env.example**: `DATABASE_URL=postgresql://...` → `PSYPI_DATABASE_NAME=psypi`

## What NOT to touch
- `build/` directory files — they are generated code, regenerated by `gleam build`
- Any other module — only `src/db.gleam` references `get_database_name()`
