## ⚠️ IMPORTANT GOTCHAS

### 1. Gleam List Representation
```javascript
// WRONG - assumes arrays
function listToArray(gleamList) { return gleamList; } // BROKEN!

// CORRECT - traverse NonEmpty/Empty classes
function listToArray(gleamList) {
  let result = [];
  let current = gleamList;
  while (current.constructor.name !== 'Empty') {
    result.push(current.head);
    current = current.tail;
  }
  return result;
}
```

### 2. Database Connection
- **psql default**: Connects to `jk` database (empty `DATABASE_URL`)
- **Node.js/pg**: Connects to `psypi` database (correct)
- **Always use**: `psql -d psypi` or set `DATABASE_URL=postgres://postgres@localhost:5432/psypi`

### 3. FFI Syntax
```gleam
// CORRECT - use @external
@external(javascript, "./cmd_utils_ffi.mjs", "execute")
pub fn execute(cmd: String) -> promise.Promise(Result(String, CmdError))

// WRONG - promise.execute() takes STRING, not function literal
promise.execute(function() { ... }) // BROKEN!
```

### 4. `psypi commit` vs `git commit`
- **ALWAYS use**: `psypi commit "message"` (triggers Gleam review)
- **NEVER use**: `git commit -m "message"` (bypasses review)
- **Exception**: When `psypi commit` is broken (e.g., FFI issues)
