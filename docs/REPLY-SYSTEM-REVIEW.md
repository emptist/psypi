### 1.4 HIGH: `get_config` FFI Type Claim — Misleading Analysis

**Claim:** "`get_config` returns `null|string` not `Some|None`, so debounce NEVER fires"  
**Reality:** This is an oversimplified reading. The FFI function returns raw JS `null` or `string`, and Gleam declares it as `-> option.Option(String)`. 

Here's the actual picture:
- `@external(javascript, ...)` for `option.Option(String)` Gleam-to-JS interop **does** treat `null` as `None` and any other value as `Some(value)`. This is Gleam's standard JS codegen convention.
- However, since the function is a raw JS export (not auto-generated by Gleam), there is indeed a **representation mismatch** risk. The `case` matching in `hook_on_agent_end.gleam` expects Gleam runtime `Some`/`None` objects but receives raw JS `null`/`string`.
- **Verdict:** This is a plausible concern but not the slam-dunk "NEVER fires" the review claims. Gleam's JS target DOES have special handling in `@external` for option types. Needs a runtime test to confirm, not static analysis.

## 2. REAL ISSUES THE REVIEWER FOUND (Confirmed)

These issues are **genuine, verified bugs**. They should be filed and tracked.

### 2.1 `memory.gleam:save()` — RETURNING id decoded with 7-field decoder [CRITICAL]

- **Line 65:** `RETURNING id` returns only `id` column
- **Line 82:** `decode.run(row, memory_decoder())` expects 7 fields
- **Result:** save() ALWAYS returns Error even though INSERT succeeds
- **Impact:** Callers may retry, creating duplicate entries

### 2.2 `memory.gleam:search()` — SELECT * missing ::text on `created_at` [CRITICAL]

- **Line 101:** `SELECT * FROM memory` — `created_at` is timestamptz, Decoder uses `decode.string`
- **Result:** search() ALWAYS fails with DecodeError

### 2.3 `skill.gleam` — Missing `::text` cast on JSONB columns [HIGH]

- **Line 137:** `SELECT ... content::text, reference_list::text` — ✅ correct
- **Line 184:** `SELECT ... content, reference_list` — ❌ no ::text (in `get_skill_by_name`)
- **Line 214:** `SELECT ... content, reference_list` — ❌ no ::text (in `update_skill_status`)

### 2.4 `inter_review.gleam` — Missing `::text` cast on `requested_at` [HIGH]

- **Lines 148, 283, 285:** `SELECT ... requested_at` — timestamptz returned as JS Date object
