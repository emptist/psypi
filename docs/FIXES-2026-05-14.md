# Fixes Applied — 2026-05-14

## Root Cause: Tool Blocking

The `tool_call` hook in `extension.js` had dangerous pattern matching that tested `inputStr` (file content) against patterns like `/rm.*-rf/i`. This meant writing a file containing "rm -rf" in the content would block the write tool.

Additionally, `agent_identity_get_resolved_identity` and `log_activity` calls crashed silently, blocking all tools.

## Solution

### 1. Split extension_generator.gleam into small modules
- `generator/tool_call.gleam` (31 lines) — Thin hook, auto-backup only
- `generator/before_agent_start.gleam` (36 lines) — Read directives from DB
- `generator/session_start.gleam` (20 lines) — Health check, [Autonomic] messages
- `generator/model_select.gleam` (19 lines) — Record model changes
- `generator/tool_result.gleam` (34 lines) — Detect errors, create directives
- `generator/agent_lifecycle.gleam` (20 lines) — Agent start/end logging

### 2. Removed dangerous pattern matching
Hooks no longer block tools based on file content.

### 3. Removed crashing calls
- `agent_identity_get_resolved_identity` from hook
- `log_activity` from hook

### 4. Added [Autonomic] prefix
A-worker messages displayed with `[Autonomic]` prefix so S-worker can distinguish them.

### 5. Renamed tools
- `psypi-my-id` → `psypi-somatic-id`
- `psypi-monitor-id` → `psypi-autonomic-id`
- `psypi-set-directive` → `psypi-direct-worker`
- `psypi-monitor-consult` → `psypi-consult-autonomic`

## Key Architectural Insights

### Alternating Current Metaphor
A-worker and S-worker alternate like AC current — never running at the same time. Each one's output becomes the other's input.

### Two Prompt Types
- **System prompt** (invisible) — directives injected by `before_agent_start`
- **User message** (visible) — `ctx.ui.notify()` displays on screen

Both are just "prompts" to the S-worker — one is system-level, one is user-level.

### Hooks are Thin
Hooks just record events and inject prompts. All intelligence is in the LLM's reasoning.

### Small + Pure = Resilience
Each Gleam module < 100 lines. Edits don't fail, code doesn't accumulate.
