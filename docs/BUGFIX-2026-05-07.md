# BUGFIX-2026-05-07 - Fix Pi Tools Returning [object Promise]

**Date:** 2026-05-07

**Bug Report:** GitHub Issue #7

---

## Problem

All Pi tools were returning `[object Promise]` or `[object Object]` instead of actual values:

```
psypi-task-add → "Task added! ID: [object Promise]"
psypi-skill-list → "Skills: [object Promise]"
psypi-broadcast-send → "Broadcast sent: [object Promise]"
```

**Root Cause:** Gleam functions return `Result<Value, Error>` type, but the JavaScript extension code wasn't unwrapping them properly.

Gleam's Result type in JavaScript:
```javascript
// Success:
{ constructor: { name: 'Ok' }, '0': value }

// Error:
{ constructor: { name: 'Error' }, '0': error }
```

The old code just did `await gleam_function()` and used the result directly, which is a Result object, not the actual value!

---

## Fix Applied

### 1. Added `unwrapGleamResult()` Helper

```javascript
function unwrapGleamResult(result) {
  if (!result) return { ok: false, error: 'null result' };
  const typeName = result.constructor?.name || '';
  if (typeName === 'Ok') {
    return { ok: true, value: result['0'] };
  }
  if (typeName === 'Error') {
    const err = result['0'];
    return { ok: false, error: err?.['0'] || err?.toString() || 'Unknown error' };
  }
  return { ok: true, value: result };
}
```

### 2. Fixed ALL 17+ Pi Tools

**Before:**
```javascript
async execute(_toolCallId, params, _signal, _onUpdate, _ctx) {
  const result = await task_add(params.title, ...);
  return { content: [{ type: "text", text: `Task added! ID: ${result}` }] };
  // BUG: result is { type: "Ok", value: "..." } not the actual ID!
}
```

**After:**
```javascript
async execute(_toolCallId, params, _signal, _onUpdate, _ctx) {
  const result = await task_add(params.title, ...);
  const taskResult = unwrapGleamResult(result);
  if (!taskResult.ok) {
    return { content: [{ type: "text", text: `Error: ${taskResult.error}` }] };
  }
  return { content: [{ type: "text", text: `Task added! ID: ${taskResult.value}` }] };
}
```

### 3. Fixed Identity Helper

Created `getIdentity()` helper that properly calls `get_resolved_identity()` with all 7 required parameters:

```javascript
async function getIdentity(permanent = false, ctx = null) {
  const sessionId = (ctx?.sessionManager?.getSessionId()) || AgentIdentityService.sessionId || '';
  const source = process.env.PSYPI_AGENT_SOURCE || 'psypi';
  const project = 'psypi';
  let gitHash = '';
  try {
    const { execSync } = await import('child_process');
    gitHash = execSync('git rev-parse HEAD', { cwd: __dirname + '/../../..' }).toString().trim();
  } catch {}
  const machineFingerprint = process.env.HOSTNAME || process.env.COMPUTERNAME || 'unknown';
  const model = ctx?.model?.id || process.env.PSYPI_MODEL || '';
  
  const result = await get_resolved_identity(permanent, sessionId, project, gitHash, machineFingerprint, source, model);
  return unwrapGleamResult(result);
}
```
