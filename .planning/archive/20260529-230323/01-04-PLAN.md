# Plan 01-04: Add Inter-Review Step to A-bot Workflow

## Objective
When A-bot wakes (S-bot idle + debounce), it should:
1. Review S-bot's recent commits (git log since last A-bot session)
2. Save inter-review to database
3. Check agent_jobs for additional work
4. Send wake-up message to S-bot with review summary (especially serious problems)

## Tasks

### Task 1: Add inter-review step to a_orchestrator.gleam
**Type:** feature
**Files:** src/a_orchestrator.gleam
**Action:**
- After reading soul and jobs from DB, before calling call_monitor:
  1. Get S-bot's recent commits since last A-bot session
  2. Create inter-review record via `inter_review.request_review()`
  3. The actual review content comes from call_monitor (A-bot's LLM thinking)
- In handle_monitor_response, before sending wake-up message:
  1. Save review result to inter_reviews table (summary, score, findings)
  2. Include review summary in wake-up message
  3. Flag serious problems (critical/high findings) prominently

**Verify:** `gleam build` succeeds

### Task 2: Add save_review_result() to inter_review.gleam
**Type:** feature
**Files:** src/inter_review.gleam
**Action:**
- Add `save_review_result(review_id, summary, score, findings)` function
- This writes the review response to inter_reviews table
- Updates status from 'pending' to 'completed'
- Sets overall_score, summary, response fields

**Verify:** `gleam build` succeeds

### Task 3: Track last A-bot session timestamp
**Type:** feature
**Files:** src/a_orchestrator.gleam, src/a_db_reader.gleam
**Action:**
- After A-bot completes its work, record timestamp in config table
- Key: `last_a_session_at`
- Use this timestamp to determine which S-bot commits to review (git log --since=<timestamp>)

**Verify:** `gleam build` succeeds

**Done when:** A-bot reviews S-bot's commits, saves review to DB, mentions review in wake-up message
