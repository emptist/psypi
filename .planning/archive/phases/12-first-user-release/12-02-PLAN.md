    Two AI agents working together inside your terminal. One answers you, one watches everything.

    ## Quick Start

    ```bash
    git clone <repo>
    cd psypi
    make setup        # installs deps, creates DB, seeds data, builds
    node bin/ppi.mjs  # start Pi with psypi loaded
    ```

    ```
    /psypi-my-id              → "I am S-psypi-..."
    /psypi-task-add title="first task"
    /psypi-issues
    /psypi-skill-list
    ```

    ## What You Get

    - 🤖 **S-bot** — your AI assistant. Answers questions, writes code, manages files.
    - 👁️ **A-bot** — autonomous monitor. Reviews commits, tracks issues, wakes S-bot when idle.
    - 📋 **Tasks** — shared work queue between both agents.
    - 🐛 **Issues** — bug tracker. Both agents can file and resolve issues.
    - 💬 **Meetings** — structured A↔S discussions.
    - 🧠 **Skills** — discoverable, searchable capability extensions (27 built-in).
    - 🔒 **Code versioning** — auto-backup before AI edits files.
    - 📚 **Learning** — agents save knowledge to memory, searchable later.

  <name>Task 2: Create Makefile</name>
  <files>Makefile</files>
  <action>
    Create a `Makefile` at project root with convenient shortcuts:

    ```makefile
    .PHONY: setup build migrate seed start clean help

    help:           ## Show this help
        @grep -E '^[a-zA-Z_-]+:.*?## .*$$' $(MAKEFILE_LIST) | sort | awk 'BEGIN {FS = ":.*?## "}; {printf "\033[36m%-15s\033[0m %s\n", $$1, $$2}'

    setup:          ## Full first-time setup
        bash bin/setup.sh

    build:          ## Build Gleam → JS and regenerate extension.js
        rm -rf build/ && gleam build
        node bin/ppi.mjs --generate-only

    migrate:        ## Run database migrations
        gleam run -m simple_migrate

    seed:           ## Seed initial data (idempotent)
        gleam run -m seed

    start:          ## Start Pi with psypi
        node bin/ppi.mjs

    minimal:        ## Start Pi in minimal mode (no session/skills)
        node bin/ppi.mjs --minimal

    clean:          ## Clean build artifacts
        rm -rf build/ extension.js
    ```
