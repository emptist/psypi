  Rules:
  - Must use @external for Node.js child_process.spawn
  - Path: relative to .gleam file location
  - Return Nil (or Result for error handling)
  
  From gleam-language skill: @external syntax:
  ```gleam
  @external(javascript, "../../some_ffi.mjs", "spawn_pi")
  pub fn spawn_pi(args: List(String)) -> Nil
  ```
  
  Create FFI helper (main_ffi.mjs):
  ```javascript
  import { spawn } from 'child_process';
  export function spawn_pi(args) {
    const pi = spawn('pi', args, { stdio: 'inherit', cwd: process.env.PSYPI_ROOT });
  }
  ```
  
  **Why:** Gleam can't directly spawn processes, needs JS FFI.
  <verify>cat gleam/psypi_core/src/psypi_cli/main_ffi.mjs 2>/dev/null || echo "FFI file needed"</verify>
