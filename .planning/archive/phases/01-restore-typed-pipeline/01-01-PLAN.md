# Plan 01-01: Restore Typed Pipeline — Move Generator Functions Back to pi_tool_call.gleam

## Objective
Restore the Phase 2H architecture by moving all generator functions from `extension_generator.gleam` back to `pi_tool_call.gleam`, where they belong. The generator functions are the typed pipeline's core — they convert `PiToolCall`/`PiEventHook`/`PiCommandReg` values into JS text through structured pattern matching. They were stripped out in commit `758b449` and inlined into `extension_generator.gleam`.

## Context
- **Phase 2H state** (commit `6eb3f4a`): `pi_tool_call.gleam` was 520 lines, containing types + all generator functions as `pub fn`
- **Current state**: `pi_tool_call.gleam` is 232 lines (types + constructors only), generator functions are private `fn` in `extension_generator.gleam`
- The "Do NOT re-extract into separate files" comment in `extension_generator.gleam` is the AI's attempt to prevent restoration

## Tasks

### Task 1: Move generator functions to pi_tool_call.gleam
**Type:** refactor
**Files:** `src/pi_tool_call.gleam`, `src/extension_generator.gleam`
**Action:**
Move these functions from `extension_generator.gleam` to `pi_tool_call.gleam`, making them `pub fn` (as they were in Phase 2H):

1. `params_to_js(params: List(PiParam)) -> String` → `pub fn`
2. `tool_args_to_js(args: List(FnArg)) -> String` → rename to `args_to_js`, make `pub fn`
3. `result_to_js(format: ResultFormat) -> String` → `pub fn`
4. `tool_to_js_text(tool: PiToolCall) -> String` → rename to `to_js_text`, make `pub fn`
5. `tool_to_import_line(tool: PiToolCall) -> String` → rename to `to_import_line`, make `pub fn`
6. `hook_success_action_to_js(action: HookSuccessAction) -> String` → make `pub fn`
7. `hook_import_line_js(module, fn_name) -> String` → rename to `hook_import_line`, make `pub fn`
8. `hook_call_expr_js(module, fn_name, args) -> String` → rename to `hook_call_expr`, make `pub fn`
9. `event_hook_to_js(hook: PiEventHook) -> String` → `pub fn`
10. `command_result_to_js(format: ResultFormat) -> String` → merge with `result_to_js` (same logic), make `pub fn`
11. `command_hook_import_line(module, fn_name) -> String` → same as `hook_import_line`, deduplicate
12. `command_hook_call_expr(module, fn_name, args) -> String` → same as `hook_call_expr`, deduplicate
13. `command_to_js(cmd: PiCommandReg) -> String` → rename to `command_to_js`, make `pub fn`

**Key deduplication:** The Phase 2H code used shared `hook_import_line` and `hook_call_expr` for both hooks and commands. The current code duplicated them as `command_hook_import_line` and `command_hook_call_expr`. Restore the shared versions.

**Also move the `HookErrorAction` type changes:** Phase 2H had `IgnoreError` variant (removed in current code). The current code only has `NotifyError`. Keep `NotifyError` only since `IgnoreError` was removed intentionally.

**Verify:** `gleam build` succeeds after the move
