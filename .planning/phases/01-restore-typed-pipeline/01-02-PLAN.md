# Plan 01-02: Move Runtime Helpers to FFI

## Objective
Move the inline JS helper functions (`unwrapGleamResult`, `gleamValueToJson`, `autonomic_wakeup_renderer`) from `extension_generator.gleam` into proper FFI modules. These are runtime JS code that gets emitted as text into `extension.js` — they should be proper JS modules imported by the generated code, not handwritten JS strings in Gleam files.

## Context
- `unwrapGleamResult` — converts Gleam `Result` to `{ ok, value/error }` at JS runtime
- `gleamValueToJson` — converts Gleam runtime objects to JSON-safe JS objects (50 lines of fragile `constructor.name` matching)
- `autonomic_wakeup_renderer` — registers a custom message renderer with Pi

These are currently emitted as JS text strings into `extension.js` by `extension_generator.gleam`. The proper approach:
1. `unwrapGleamResult` → move to `pi_extension_ffi.mjs` as a proper export, imported by `extension.js`
2. `gleamValueToJson` → replace with `gleam_json` encoders in domain modules (long-term); short-term move to `pi_extension_ffi.mjs`
3. `autonomic_wakeup_renderer` → move to `pi_extension_ffi.mjs` as a proper export

## Tasks

### Task 1: Move unwrapGleamResult to pi_extension_ffi.mjs
**Type:** refactor
**Files:** `src/pi_extension_ffi.mjs`, `src/extension_generator.gleam`, `src/extension.js` (generated)
**Action:**
1. Add `unwrapGleamResult` function to `pi_extension_ffi.mjs` as an export
2. In `extension_generator.gleam`, remove `unwrap_gleam_result_js()` function
3. In `imports_text()`, add import line for `unwrapGleamResult` from `pi_extension_ffi.mjs`
4. The generated `extension.js` should import `unwrapGleamResult` instead of defining it inline

**Verify:** `gleam run -m extension_generator` produces `extension.js` that imports `unwrapGleamResult` from FFI

### Task 2: Move gleamValueToJson to pi_extension_ffi.mjs
**Type:** refactor
**Files:** `src/pi_extension_ffi.mjs`, `src/extension_generator.gleam`
**Action:**
1. Add `gleamValueToJson` function to `pi_extension_ffi.mjs` as an export
2. In `extension_generator.gleam`, remove `gleam_value_to_json_js()` function
3. In `imports_text()`, add import line for `gleamValueToJson` from `pi_extension_ffi.mjs`
4. The generated `extension.js` should import `gleamValueToJson` instead of defining it inline

**Note:** Long-term, each domain module should define `gleam_json` encoders, and the generated code should call those instead of `gleamValueToJson`. But that's a larger change. For now, moving the function to FFI is already an improvement — it removes the handwritten JS string from Gleam source.

**Verify:** `gleam run -m extension_generator` produces `extension.js` that imports `gleamValueToJson` from FFI

### Task 3: Move autonomic_wakeup_renderer to pi_extension_ffi.mjs
**Type:** refactor
**Files:** `src/pi_extension_ffi.mjs`, `src/extension_generator.gleam`
**Action:**
1. Add `registerAutonomicWakeupRenderer` function to `pi_extension_ffi.mjs` as an export
2. In `extension_generator.gleam`, remove `autonomic_wakeup_renderer_js()` function
3. In `imports_text()`, add import line for `registerAutonomicWakeupRenderer`
4. In `generate()`, replace the inline renderer text with a call to the imported function: `registerAutonomicWakeupRenderer(pi);`

**Verify:** `gleam run -m extension_generator` produces `extension.js` that imports and calls `registerAutonomicWakeupRenderer`

**Done criteria:** `extension.js` imports helpers from FFI, no inline JS helper definitions, runtime behavior unchanged
