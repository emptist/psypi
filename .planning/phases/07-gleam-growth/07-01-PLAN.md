## Architecture Proven:
```
bin/psypi.mjs (Gleam-compiled, spawns Pi)
    ↓
Pi TUI loads
    ↓
extension.js (REQUIRED by Pi - thin wrapper, ~30 lines)
    ↓ imports
gleam/.../module1.mjs (Gleam logic)
gleam/.../module2.mjs (Gleam logic)
```

## Key Rules from Skills:
- **extension.js is MANDATORY** (Pi requirement: `export default function(pi)`)
- **Gleam uses named exports** (not `export default`)
- **Gleam @external**: `@external(javascript, "./helpers.js", "function")`
- **Files < 100 lines** (Gleam philosophy: Small + Pure = Resilience)
- **No pnpm build after migration** (only `gleam build`)
</proven_findings>
