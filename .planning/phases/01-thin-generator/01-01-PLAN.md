# PLAN: Eliminate Hand-Written JS Strings from Generator

## Core Design Principle

**Generator 的用意：杜绝任何手写 JS 或 JS string。所有 JS 都是通过 Gleam 代码编译产生的。任何手写 JS string 都是 AI 违反规则。**

## Problem Statement

### Current State

`pi_tool_call.gleam` 中有大量手写 JS string 函数和类型：

1. **`*_to_js` 函数**（10个）：将 Gleam 数据转为 JS 源码文本
   - `to_js_text()`, `event_hook_to_js()`, `command_to_js()`, `message_renderer_to_js()`
   - `params_to_js()`, `args_to_js()`, `result_to_js()`
   - `hook_error_to_js()`, `success_action_to_js()`, `theme_color_to_js()`

2. **`FnArg` type 中的 `JsLiteral`**：允许在 Gleam 代码中嵌入任意 JS 表达式

3. **`FromParam` 中的 JS 表达式**：虽然是"参数提取"，但实际是 JS 表达式字符串

### Audit Results (from ppitest.mjs)

| Category                   | Count   | Examples                                                           |
| -------------------------- | ------- | ------------------------------------------------------------------ |
| JsLiteral                  | 15      | `lit("ctx")`, `lit("pi")`, `lit("5")`, `lit("({ is_idle: ... })")` |
| FromParam (simple)         | 54      | `from_param("params.title                                          |  | \"\"")`  |
| FromParam (optional)       | 17      | `from_param("params?.status                                        |  | null")`  |
| FromParam (parseInt)       | 10      | `from_param("parseInt(params.limit                                 |  | '10')")` |
| FromParam (event)          | 4       | `from_param("event.toolName                                        |  | ''")`    |
| FromParam (string literal) | 3       | `from_param("'psypi'")`                                            |
| FromParam (null)           | 3       | `from_param("null")`                                               |
| FromParam (other)          | 4       | `from_param("ctx.model")`, `from_param("JSON.stringify(...)")`     |
| **Total**                  | **110** |                                                                    |

**所有 110 个都是手写 JS string，违反设计意图。**

## Target Architecture

### Key Insight

`PiToolCall`、`PiEventHook` 等 type 的 value 在 `gleam build` 后变成 JS object。
extension.js 应该直接使用这些 JS object 来注册 Pi 工具/钩子，
而不是由 generator 把它们解构成 JS string 再写入 extension.js。

### Verified by Experiment

ppitest.mjs 验证了：
- PiToolCall JS object 包含 name, module, fn_name, params, args, result_format
- 动态 import `./build/dev/javascript/psypi/${module}.mjs` 可行（42/44 成功，2个因依赖 Pi 运行时而失败，在 Pi 内部可用）
- 所有属性都可以在运行时读取

### New Flow

```
gleam build → PiToolCall/PiEventHook 编译成 JS object
                ↓
extension.js（静态文件）import Gleam-compiled 模块
                ↓
extension.js 读取 JS object，动态 import 模块，注册 Pi 工具/钩子
                ↓
ppi.mjs 直接 spawn Pi 加载 extension.js
```

### extension.js — Static Registration Template

extension.js 不再由 Gleam generator 生成。它是一个**固定的、通用的注册器**。

```javascript
// extension.js — STATIC FILE, DO NOT MODIFY
// Reads Gleam-compiled registration data and registers with Pi.
import { all_tools, all_event_hooks, all_commands, all_message_renderers } from './build/dev/javascript/psypi/extension_generator.mjs';
import { unwrapGleamResult, gleamValueToJson } from './build/dev/javascript/psypi/pi_extension_ffi.mjs';
import { Text, Box } from '@earendil-works/pi-tui';
import { record_trigger } from './build/dev/javascript/psypi/event_hooks.mjs';

// --- Utility functions ---

function gleamListToArray(l) {
  const arr = [];
  let cur = l;
  while (cur && cur.constructor.name === 'NonEmpty') { arr.push(cur.head); cur = cur.tail; }
  return arr;
}

function paramsToJsonSchema(params) {
  const arr = gleamListToArray(params);
  if (arr.length === 0) return { type: 'object', properties: {} };
  const properties = {};
  const required = [];
  for (const p of arr) {
    properties[p.name] = { type: p.param_type };
    if (p.required) required.push(p.name);
  }
  return { type: 'object', properties, required };
}

function buildArgs(fnArgs, params, event, ctx, pi) {
  return gleamListToArray(fnArgs).map(a => {
    const typeName = a.constructor.name;
    switch (typeName) {
      case 'ParamField': return params[a.name] ?? a.default_0 ?? '';
      case 'OptionalParamField': return params?.[a.name] ?? null;
      case 'IntParamField': return parseInt(params?.[a.name] ?? String(a.default_0));
      case 'EventField': return event?.[a.name] ?? a.default_0 ?? '';
      case 'EventJsonField': return JSON.stringify(event?.[a.name] ?? '');
      case 'EventFilePath': return event?.input?.path || event?.input?.filePath || '';
      case 'CtxField': return ctx?.[a.name];
      case 'ArgsField': return params || '';  // for commands, params = args string
      case 'Ctx': return ctx;
      case 'Pi': return pi;
      case 'StringConst': return a[0];
      case 'IntConst': return a[0];
      case 'NullConst': return null;
      default: return undefined;
    }
  });
}

function formatResult(format, value) {
  const typeName = format.constructor.name;
  switch (typeName) {
    case 'RawJson': return JSON.stringify(gleamValueToJson(value));
    case 'Template': return format[0].replace('${value}', String(value));
    case 'CustomJs': return value;  // tool_fn already returns formatted string
    default: return String(value);
  }
}

function makeToolResult(text) {
  return { content: [{ type: 'text', text: String(text) }] };
}

function makeToolError(text) {
  return { content: [{ type: 'text', text: `Error: ${String(text)}` }] };
}

function reportError(pi, source, error) {
  pi.sendMessage({
    customType: 'autonomic-error',
    content: source + ' error: ' + String(error),
    display: true
  }, { triggerTurn: false, deliverAs: 'followUp' });
}

// --- Registration functions ---

async function registerTools(pi) {
  const tools = gleamListToArray(all_tools());
  for (const tool of tools) {
    const mod = await import('./build/dev/javascript/psypi/' + tool.module + '.mjs');
    const fn = mod[tool.fn_name];
    pi.registerTool({
      name: tool.name,
      description: tool.description,
      parameters: paramsToJsonSchema(tool.params),
      execute: async (_id, params, _sig, _upd, ctx) => {
        try {
          const result = await fn(...buildArgs(tool.args, params, null, ctx, pi));
          const r = unwrapGleamResult(result);
          if (!r.ok) {
            reportError(pi, 'Tool ' + tool.name, r.error);
            return makeToolError(r.error);
          }
          return makeToolResult(formatResult(tool.result_format, r.value));
        } catch (e) {
          reportError(pi, 'Tool ' + tool.name, e.message || String(e));
          return makeToolError(e.message || String(e));
        }
      }
    });
  }
}

async function registerHooks(pi) {
  const hooks = gleamListToArray(all_event_hooks());
  for (const hook of hooks) {
    const typeName = hook.constructor.name;

    if (typeName === 'PiSystemPromptHook') {
      pi.on(hook.event_name, async (event, ctx) => {
        const mod = await import('./build/dev/javascript/psypi/' + hook.module + '.mjs');
        try {
          const result = await mod[hook.fn_name](...buildArgs(hook.args, null, event, ctx, pi));
          const r = unwrapGleamResult(result);
          if (r.ok) {
            await record_trigger(hook.event_name);
            return { systemPrompt: r.value };
          } else {
            reportError(pi, 'Hook ' + hook.event_name, r.error);
            await record_trigger(hook.event_name);
            return undefined;
          }
        } catch (e) {
          reportError(pi, 'Hook ' + hook.event_name, e.message || String(e));
          return undefined;
        }
      });
    }

    else if (typeName === 'PiEventHook') {
      const guard = hook.guard?.constructor?.name === 'Some' ? hook.guard[0] : null;
      pi.on(hook.event_name, async (event, ctx) => {
        if (guard && !evalGuard(guard, event, ctx)) return;
        const mod = await import('./build/dev/javascript/psypi/' + hook.module + '.mjs');
        try {
          const result = await mod[hook.fn_name](...buildArgs(hook.args, null, event, ctx, pi));
          const r = unwrapGleamResult(result);
          if (r.ok) {
            handleSuccess(hook.on_success, ctx, hook.event_name);
          } else {
            reportError(pi, 'Hook ' + hook.event_name, r.error);
          }
          await record_trigger(hook.event_name);
        } catch (e) {
          reportError(pi, 'Hook ' + hook.event_name, e.message || String(e));
        }
      });
    }

    else if (typeName === 'PiDebouncedHook') {
      // Debounce state
      let timerId = null;
      let debounceMs = null;
      let hasWorked = false;

      // Main hook
      pi.on(hook.event_name, async (event, ctx) => {
        if (!hasWorked) return;
        const wasWaiting = timerId !== null;
        if (timerId) clearTimeout(timerId);
        timerId = null;

        const schedule = (ms) => {
          timerId = setTimeout(async () => {
            timerId = null;
            hasWorked = false;
            const mod = await import('./build/dev/javascript/psypi/' + hook.module + '.mjs');
            try {
              const result = await mod[hook.fn_name](...buildArgs(hook.args, null, event, ctx, pi));
              const r = unwrapGleamResult(result);
              if (r.ok) {
                handleSuccess(hook.on_success, ctx, hook.event_name);
              } else {
                reportError(pi, 'Hook ' + hook.event_name, r.error);
              }
              await record_trigger(hook.event_name);
            } catch (e) {
              reportError(pi, 'Hook ' + hook.event_name, e.message || String(e));
            }
          }, ms);
          if (!wasWaiting) ctx.ui.notify('[A-agentbot] Waiting for S to become idle...', 'status');
        };

        // Lazy-init debounce ms
        if (debounceMs == null) {
          const msMod = await import('./build/dev/javascript/psypi/' + hook.debounce_ms_module + '.mjs');
          const debounceResult = await msMod[hook.debounce_ms_fn]();
          const dr = unwrapGleamResult(debounceResult);
          if (!dr.ok) {
            reportError(pi, 'Hook ' + hook.event_name, 'debounce config: ' + dr.error);
            return;
          }
          debounceMs = dr.value;
        }
        schedule(debounceMs);
      });

      // Cancel hooks
      const cancelOn = gleamListToArray(hook.cancel_on);
      for (const ev of cancelOn) {
        pi.on(ev, async (_event, _ctx) => {
          if (ev === 'agent_start') hasWorked = true;
          if (timerId) {
            clearTimeout(timerId);
            timerId = null;
            const reason = ev === 'agent_start' ? 'S became active' : 'user activity';
            _ctx.ui.notify('[A-agentbot] Waiting cancelled — ' + reason, 'status');
          }
        });
      }
    }
  }
}

async function registerCommands(pi) {
  const cmds = gleamListToArray(all_commands());
  for (const cmd of cmds) {
    const mod = await import('./build/dev/javascript/psypi/' + cmd.module + '.mjs');
    pi.registerCommand(cmd.name, {
      description: cmd.description,
      handler: async (args, ctx) => {
        try {
          const result = await mod[cmd.fn_name](...buildArgs(cmd.args, args, null, ctx, pi));
          const r = unwrapGleamResult(result);
          if (r.ok) {
            return makeToolResult(formatResult(cmd.result_format, r.value));
          } else {
            reportError(pi, 'Command ' + cmd.name, r.error);
            return makeToolError(r.error);
          }
        } catch (e) {
          reportError(pi, 'Command ' + cmd.name, e.message || String(e));
          return makeToolError(e.message || String(e));
        }
      }
    });
  }
}

function registerRenderers(pi) {
  const renderers = gleamListToArray(all_message_renderers());
  const colorMap = { Accent: 'accent', Warning: 'warning', Error: 'error', Dim: 'dim' };
  for (const r of renderers) {
    const prefixColor = colorMap[r.prefix_color.constructor.name] || 'accent';
    const contentColor = colorMap[r.content_color.constructor.name] || 'accent';
    pi.registerMessageRenderer(r.custom_type, (message, { expanded }, theme) => {
      let text = theme.fg(prefixColor, r.prefix + ' ');
      text += theme.fg(contentColor, message.content);
      if (r.show_details && expanded && message.details) {
        text += '\n' + theme.fg('dim', JSON.stringify(message.details, null, 2));
      }
      const box = new Box(1, 1, (t) => theme.bg('customMessageBg', t));
      box.addChild(new Text(text, 0, 0));
      return box;
    });
  }
}

function evalGuard(guard, event, ctx) {
  // Guards are simple expressions like "ctx.model" or "event.model"
  try {
    if (guard === 'ctx.model') return !!ctx.model;
    if (guard === 'event.model') return !!event.model;
    return true;
  } catch { return false; }
}

function handleSuccess(action, ctx, eventName) {
  const typeName = action.constructor.name;
  switch (typeName) {
    case 'SilentSuccess': break;
    case 'NotifySuccess': ctx.ui.notify(action[0], 'info'); break;
    case 'SetStatus': ctx.ui.setStatus(action[0], action[1]); break;
  }
}

// --- Main ---

export default async function(pi) {
  registerRenderers(pi);
  await registerHooks(pi);
  await registerTools(pi);
  await registerCommands(pi);
}
```

## Step-by-Step Changes

### Step 1: Redesign FnArg type

**Current**:
```gleam
pub type FnArg {
  JsLiteral(String)    // ← 手写 JS string
  FromParam(String)    // ← 也是手写 JS string
}
```

**New**:
```gleam
pub type ParamSource {
  ParamField(name: String, default: Option(String))     // params.name ?? default
  OptionalParamField(name: String)                       // params?.name ?? null
  IntParamField(name: String, default: Int)              // parseInt(params?.name ?? default)
  EventField(name: String, default: Option(String))      // event?.name ?? default
  EventJsonField(name: String)                           // JSON.stringify(event?.name ?? '')
  EventFilePath                                          // event?.input?.path || event?.input?.filePath || ''
  CtxField(name: String)                                 // ctx.name (e.g. ctx.model)
  ArgsField                                              // args || '' (command handler)
}

pub type FnArg {
  FromParam(ParamSource)    // 从 Pi 回调参数提取
  Ctx                       // Pi ctx 对象
  Pi                        // Pi pi 对象
  StringConst(String)       // 字符串常量
  IntConst(Int)             // 整数常量
  NullConst                 // null
}
```

### Step 2: Fix get_enriched_identity to use FFI functions

Current `my_id_tool()` uses `JsLiteral` to construct a JS object:
```gleam
lit("({ is_idle: ctx.isIdle(), source: (ctx.model?.provider || ''), ... })")
```

But `pi_extension_ffi.mjs` already has FFI functions:
- `ctx_is_idle(ctx)` → `ctx.isIdle()`
- `ctx_get_source(ctx)` → `ctx.model?.provider || ''`
- `ctx_get_model_id(ctx)` → `ctx.model?.id || ''`
- `ctx_get_thinking_level(ctx)` → `ctx.model?.thinkingLevel || ''`

Fix: `get_enriched_identity` should accept `ctx` directly and use FFI functions
to extract properties internally.

```gleam
pub fn get_enriched_identity(ctx: a) -> promise.Promise(Result(EnrichedIdentity, IdentityError)) {
  let is_idle = ctx_is_idle(ctx)
  let source = ctx_get_source(ctx)
  let model = ctx_get_model_id(ctx)
  let thinking_level = ctx_get_thinking_level(ctx)
  let cwd = ctx_get_cwd(ctx)
  let project = resolve_project(cwd)
  let global = case check_git_exists(cwd) {
    True -> False
    False -> True
  }
  let resolved_ctx = IdentityContext(
    is_idle: is_idle,
    project: project,
    source: source,
    model: model,
    thinking_level: thinking_level,
    global: global,
    cwd: cwd,
  )
  // ... rest unchanged
}
```

Then `my_id_tool()` uses `Ctx` instead of `JsLiteral`:
```gleam
pub fn my_id_tool() -> PiToolCall {
  PiToolCall(
    name: "psypi-my-id",
    description: "...",
    params: [],
    module: "agent_identity",
    fn_name: "get_enriched_identity",
    args: [Ctx],  // ← was lit("({ is_idle: ... })")
    result_format: raw_json(),
  )
}
```

### `??` vs `||` Behavior Change

New `ParamSrc` generates `??` (nullish coalescing) instead of `||` (logical OR):
- `ParamField("title", Some(""))` → `params.title ?? ""` (was `params.title || ""`)
- `OptionalParamField("status")` → `params?.status ?? null` (was `params?.status || null`)

`??` is more correct: only falls back on `null`/`undefined`, not on empty string or zero.
In Pi tool context, LLM-generated params won't be empty strings for required fields,
so this is a safe improvement with no practical behavior change.

### Detailed Diff Analysis: Old vs New JS Output

#### Pitfall 1: `??` vs `||` for Optional String Params

**Affected**: `task_list`, `skill_list` (opt_param)

```
Old: params?.status || null    → "" || null = null
New: params?.status ?? null    → "" ?? null = ""
```

If LLM sends `status: ""`, old code treats it as null, new code preserves it.
Gleam function receives `String` (not `Option(String)`), so `""` vs `null` matters.
In practice, LLM won't send empty string for optional params, so **low risk**.

#### Pitfall 2: `parseInt()` Wrapping for Int Params

**Affected**: `memory_search` (limit), `learning_save` (importance)

```
Old: (params.importance || 5)           → number directly
New: parseInt(params?.importance ?? '5') → parseInt of number/string
```

Differences:
- `importance = 0`: old → `5` (0 is falsy), new → `0` (0 is not nullish). **New is more correct**.
- `importance = 3.7`: old → `3.7` (float to Gleam Int), new → `3` (parseInt truncates). **New is safer**.
- `importance = "3"`: old → `"3"` (string to Gleam Int = crash), new → `3`. **New is more robust**.
- `importance = undefined`: old → `5`, new → `parseInt('5')` = `5`. **Same**.
- `importance = "abc"`: old → `"abc"` (crash), new → `NaN` (also problematic). **Both bad**.

**Verdict**: `parseInt` wrapping is an improvement for the common case (number from JSON).
The NaN case for invalid strings is no worse than the old crash.

#### Pitfall 3: `params.xxx` vs `params?.xxx` (Optional Chaining)

**Affected**: `IntParamField`, `OptionalParamField`

```
Old: params.limit || '10'       → throws if params is undefined
New: params?.limit ?? '10'      → returns undefined if params is undefined
```

In Pi tool context, `params` is always an object (never undefined), so **no practical difference**.

#### Pitfall 4: `my_id_tool` — Complete Parameter Change

```
Old: ({ is_idle: ctx.isIdle(), source: ctx.model?.provider || '', ... })
New: ctx
```

Old code constructed a 4-field plain object. New code passes raw `ctx` object.
Old Gleam: `get_enriched_identity(IdentityContext)` — reads `.is_idle`, `.source`, etc.
New Gleam: `get_enriched_identity(ctx: a)` — uses FFI to call `ctx.isIdle()`, etc.

**Risk**: The raw `ctx` object has many more properties than the 4-field object.
But since we only access via FFI (not by reading fields), this is safe.
The FFI functions (`ctx_is_idle`, `ctx_get_source`, etc.) only read specific properties.

**Timing**: Both compute `ctx.isIdle()` synchronously at call time. No async timing difference.

#### Pitfall 5: Quote Style Difference

```
Old: from_param("'psypi'")  → 'psypi' (single quotes)
New: new_arg(str("psypi"))  → "psypi" (double quotes)
```

Both are valid JS string literals. **No functional difference**.

#### Pitfall 6: `Option` Type Encoding in JS (Future Static extension.js)

When moving to static extension.js, `ParamField("title", Some(""))` compiles to:
```javascript
{ name: "title", default: { 0: "" } }  // Some("")
{ name: "title", default: {} }           // None
```

The static extension.js must handle `ps.default?.[0]` to extract Option values.
This depends on Gleam's stable compilation convention. **Low risk but must be documented**.
